# Editor

`PulseForgeEditor` is a separate application target. The engine and `PulseForgeGame` do not depend on ImGui; the editor owns its ImGui docking shell. Vulkan is the default editor renderer, with an editor-local ImGui renderer built on PulseForge's shader, buffer, texture, binding, pipeline, and draw APIs. The OpenGL fallback remains available for the editor shell, but does not provide the scene viewport. Vulkan mode keeps ImGui platform viewports disabled because the renderer currently owns one swapchain.

The File menu can create and open `.pfproj` projects and close the active project. New projects include an empty `Assets/Main.scene`. The Scene menu creates, opens, and saves managed `.scene` assets; the Content Browser can choose the project startup scene. Native file dialogs are provided by the vendored NativeFileDialog dependency.

The Content Browser lists registered assets in project-relative path order, supports importing external source files into `Assets`, and displays asset UUIDs on hover. Select an asset to move or rename it while preserving its UUID, duplicate it with a new UUID, or delete it with its sidecar after confirmation. Moving and duplicating preserve the asset extension. Deleting the open or configured startup scene is blocked; deletion may leave other serialized UUID references unresolved. Double-clicking a scene asset opens it by UUID. Select a `.prefab` asset and choose `Instantiate in Scene` to add a new instance to the open scene. The Hierarchy displays parent/child entities and supports selection, creation, duplication, deletion, reparenting through entity context menus, and creating a managed prefab from the selected entity subtree. Reparenting preserves local transforms. The Inspector edits entity names and local transforms, and adds, removes, and edits the currently supported camera, mesh renderer, physics, audio, and script components. Asset references are selected from registered project assets and stored by UUID. The Console shows the latest 2,000 core and client log messages with severity coloring. Project or scene changes and application close prompt to save, discard, or cancel unsaved scene edits; discard reloads the last saved scene asset by UUID.

In Edit mode, the Scene Viewport uses a transient editor camera; navigating it does not add an entity or dirty the authored scene. Right-click and drag over the viewport to look, use WASD to move, Q/E to move vertically, and Shift to move faster. Releasing the right mouse button or leaving the window restores the prior cursor mode. The camera resets when the project or scene is replaced. Play starts scripts, fixed-step physics, and spatial audio on a serialized copy of the open scene; the viewport then uses that runtime scene's primary camera. Stop discards the runtime copy and restores the editor camera view. The viewport resizes its offscreen target in quantized steps to avoid rebuilding render resources for every small panel-size change. Transform gizmos and a separate game viewport are not implemented yet.

Build the target with the default `PULSEFORGE_BUILD_EDITOR=ON` CMake option, or set it to `OFF` for runtime-only builds. The editor currently targets Windows. To use the transitional OpenGL shell instead of Vulkan, configure with `-DPULSEFORGE_EDITOR_RENDERER=OpenGL`.
