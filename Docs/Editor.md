# Editor

`PulseForgeEditor` is a separate application target. The engine and `PulseForgeGame` do not depend on ImGui; the editor owns its ImGui docking shell. Vulkan is the default editor renderer, with an editor-local ImGui renderer built on PulseForge's shader, buffer, texture, binding, pipeline, and draw APIs. The OpenGL fallback remains available for the editor shell, but does not provide the scene viewport. Vulkan mode keeps ImGui platform viewports disabled because the renderer currently owns one swapchain.

On first use, the editor creates a default dock layout with Hierarchy on the left, Scene Viewport in the center, Inspector on the right, and Content Browser/Console as bottom tabs. Scene Viewport, Hierarchy, Inspector, Content Browser, and Console are visible by default; the Scene project/status utility panel is hidden by default. The Window menu toggles every panel, and Window > Reset Layout restores the current source-defined default without changing the open project or scene. Closing a panel with its title-bar close button uses the same visibility state as the menu.

The current workspace is stored in `%LOCALAPPDATA%\PulseForge\Editor\imgui.ini`; Dear ImGui persists docking/window geometry there and PulseForge stores versioned panel visibility alongside it. The editor imports a legacy `imgui.ini` from its working directory when no per-user workspace exists. For isolated editor tests, `PULSEFORGE_EDITOR_SETTINGS_DIR` can override the workspace directory without importing the legacy file. A change to the source-defined default-layout version does not overwrite an existing workspace: defaults are constructed only when no saved dockspace/panel workspace exists or when the user explicitly resets the layout. Future panels should declare a default-visibility policy; absent visibility keys use that policy when older workspace state is loaded. The OpenGL editor shell uses the same workspace state and panel menu.

The editor bundles Inter 4.1 Regular and SemiBold at a 15 px base size for interface text, plus JetBrains Mono 2.304 Regular at 14 px for Console messages. Its explicit text atlas policy covers Basic Latin, Latin-1, Latin Extended-A/B, IPA extensions, combining marks, Latin Extended Additional, Greek, Cyrillic, General Punctuation, and Currency Symbols; CJK ranges are deliberately excluded from the static atlas. The selected Font Awesome Free Solid 7.3.0 glyphs are merged into both interface and emphasis fonts, so active icon-bearing controls retain their icons. Monospace remains text-only. Fonts are registered before renderer initialization. Vulkan builds a legacy static RGBA atlas before its custom renderer uploads it, logs the atlas dimensions, and checks that required glyphs are baked. The pinned ImGui OpenGL backend supports dynamic font textures, so EditorStyle leaves atlas construction and updates to that backend and checks the bundled font sources instead. FreeType is used for OTF icon outlines. Bundled files are copied beside the editor under `EditorAssets/`, so the editor has no runtime network or system-font requirement. Font, icon, FreeType license, and provenance notices are under `EditorAssets/ThirdParty/` and in the source `PulseForgeEditor/Assets/ThirdParty/` directory. Missing custom fonts fall back to Dear ImGui's built-in font; missing icons leave action labels textual. New panels should use the editor's `EditorStyle`/`EditorIcon` helpers instead of raw icon codepoints. Font sizes are currently startup defaults; dynamic per-monitor font-atlas rebuilding is not enabled.

Editor typography, spacing, and the restrained slate/blue accent palette are centralized in `EditorStyle`. Palette tokens are display-space sRGB colors; Vulkan style assignment converts RGB channels to linear values for its sRGB swapchain, while the OpenGL fallback uses the display values directly. Regular interface text is used by default, SemiBold is reserved for product emphasis and active viewport tools, and Console messages use JetBrains Mono. Icon+text helpers preserve UTF-8 boundaries when bounded labels must be shortened. Panel window names remain stable to preserve saved docking identities; the theme does not change the default workspace topology or persistence policy.

The File menu can create and open `.pfproj` projects and close the active project. New projects include an empty `Assets/Main.scene`. The Scene menu creates, opens, and saves managed `.scene` assets; the Content Browser can choose the project startup scene. Native file dialogs are provided by the vendored NativeFileDialog dependency.

The Content Browser lists registered assets in project-relative path order, supports importing external source files into `Assets`, and displays asset UUIDs on hover. Select an asset to move or rename it while preserving its UUID, duplicate it with a new UUID, or delete it with its sidecar after confirmation. Moving and duplicating preserve the asset extension. Deleting the open or configured startup scene is blocked; deletion may leave other serialized UUID references unresolved. Double-clicking a scene asset opens it by UUID. Select a `.prefab` asset and choose `Instantiate in Scene` to add a new instance to the open scene. The Hierarchy displays parent/child entities and supports selection, creation, duplication, deletion, reparenting through entity context menus, and creating a managed prefab from the selected entity subtree. Reparenting preserves local transforms. The Inspector edits entity names and local transforms, and adds, removes, and edits the currently supported camera, mesh renderer, physics, audio, and script components. Asset references are selected from registered project assets and stored by UUID. The Console shows the latest 2,000 core and client log messages with severity coloring. Project or scene changes and application close prompt to save, discard, or cancel unsaved scene edits; discard reloads the last saved scene asset by UUID.

In Edit mode, the Scene Viewport uses a transient editor camera; navigating it does not add an entity or dirty the authored scene. Right-click and drag over the viewport to look, use WASD to move, Q/E to move vertically, and Shift to move faster. Releasing the right mouse button or leaving the window restores the prior cursor mode. The camera resets when the project or scene is replaced.

Click a rendered mesh to select its entity; clicking empty viewport space clears the selection. The same selection is shown in the Hierarchy and Inspector. Picking tests imported mesh triangles on the CPU, so it follows entity and parent transforms but is limited to the static glTF primitive format currently supported by the mesh importer. Choose Translate, Rotate, or Scale in the Scene Viewport toolbar and drag a colored axis, ring, or endpoint handle. Gizmos use local axes and edit the selected entity's authored local transform, preserving hierarchy semantics. A render-target resize safely ends an active gizmo drag. The scene becomes dirty only when the transform changes. Picking and gizmos are disabled during Play.

Play starts scripts, fixed-step physics, and spatial audio on a serialized copy of the open scene; the viewport then uses that runtime scene's primary camera. Stop discards the runtime copy and restores the editor camera view. The viewport resizes its offscreen target in quantized steps to avoid rebuilding render resources for every small panel-size change. A separate game viewport, world-axis gizmos, multi-selection, and undo/redo are not implemented yet.

Build the target with the default `PULSEFORGE_BUILD_EDITOR=ON` CMake option, or set it to `OFF` for runtime-only builds. The editor currently targets Windows. To use the transitional OpenGL shell instead of Vulkan, configure with `-DPULSEFORGE_EDITOR_RENDERER=OpenGL`.
