# Asset provenance

The geometry, mask texture, scene layout, and materials are original lightweight procedural content created for PulseForge:

- `Assets/Models/UnitCube.gltf` is generated from six indexed cube faces by `GenerateAssets.ps1`.
- `Assets/Textures/FenceGrid.png` is generated as a 128×128 RGBA cutout grid by `GenerateAssets.ps1`.
- Scene layout and material descriptions are authored specifically for this project.

- `Assets/Environments/studio_small_01_1k.hdr` — Poly Haven, **Studio Small 01**, CC0 1.0 Universal. Source: <https://polyhaven.com/a/studio_small_01>. The source asset is bundled locally for offline use; no conversion was performed.

The included HDRI is CC0 and requires no attribution, but is credited here for provenance. No third-party source code or runtime services are required.
